# Hair Mentor Salon — Digital Style Edition

Responsive one-page static salon site built with HTML, CSS and vanilla JavaScript, no React.

## Open
Open `index.html` in a browser. No npm or server required. External photographs and Google Fonts require internet access.

## Features
- Full-viewport automatic hero carousel, arrows, progress indicator.
- Responsive floating navigation and accessible mobile menu.
- Interactive service selection with changing image and description.
- Two continuously sliding black-and-white portrait gallery rows, with pause button and full-screen lightbox.
- Editorial salon sections, CSS reveal effects, responsive layout.
- Appointment enquiry form that copies a message, *not* a real booking integration.

## Before launch
1. Replace illustrative third-party photos with licensed images or actual salon photos. URLs use Unsplash-hosted imagery; verify rights, suitability and loading. Gallery portraits represent illustrative style inspiration, **not Hair Mentor customers**.
2. Add the actual salon logo, address, contact number, hours, Instagram, Google Maps, and a direct WhatsApp booking number.
3. Connect booking to a real scheduling backend if confirmed appointments are required.
4. Test all images across browsers/devices and optimize or self-host licensed images for production.

## Files
- `index.html` — complete markup
- `style.css` — responsive editorial styling
- `script.js` — all animation and interaction behavior
